Fuel Cell 3D Simulation Documentation
=====================================

This documentation covers the **fuel_cell_3D** codebase, a meshfree simulation
framework for 3D solid oxide fuel cell (SOFC) analysis using the Reproducing
Kernel Particle Method (RKPM).

The code solves coupled electrochemical-mechanical problems in solid oxide fuel
cells, including:

* Oxygen ion diffusion in electrolyte
* Electron transport in electrodes
* Gas diffusion in pores
* Butler-Volmer electrochemical kinetics
* Thermo-mechanical stress analysis
